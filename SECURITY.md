# Security policy

Please do not publish exploitable server, client, protocol, authentication, or
update-channel vulnerabilities in a public issue. Report them privately through
GitHub's security-advisory interface for `atrinik/classic` and include affected
versions, reproduction conditions, impact, and any proposed remediation.

Only the current `main` line is supported while the consolidated classic release
pipeline is being established. Historical component releases remain available
from their archived source repositories but receive no separate security line.
