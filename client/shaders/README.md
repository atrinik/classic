# GPU shader artifacts

`map.hlsl` is the single authoritative shader source. Release builds consume
checked-in SPIR-V, DXIL, and MSL artifacts generated by
`tools/generate_gpu_shaders.sh`; the client has no runtime shader compiler.

The pinned toolchain is:

- Microsoft DirectXShaderCompiler `v1.9.2607`, Linux archive SHA-256
  `55665c87824051ed4774ff3280a79ccbbb7d39243b9736ca5e98222134112d54`;
- KhronosGroup SPIRV-Cross
  `9c3c8e2cefdd8194b193bb8ed2fdff4d5527e382`.

Generation is a maintainer operation and must reproduce the checked-in bytes.
The build validates the artifact manifest rather than downloading tools.
