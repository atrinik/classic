# Contributing

Open changes through a pull request whose title uses Conventional Commits
style. Follow the build and test procedure in `INSTALL` and keep compiler
warnings enabled.

Update dependency locks only to immutable published releases. Verify the tag,
commit, release-asset URL, and SHA-256 digest independently before committing a
lock update. Do not introduce Git submodules.

The repository's GPL-2.0-or-later licensing and bundled third-party notices
must be preserved. Do not add references to confidential or unreleased Atrinik
projects, and do not describe Atrinik components as "legacy".
